# Samples

Keep only non-copyrighted toy samples here.

Good sample files include tiny synthetic binaries created specifically for tests or documentation. Repo-safe survey aids such as manually transcribed glyph maps are also allowed when they contain no copied game assets.

Current glyph-map seeds:

- `glyph_map_seed.csv`: partial UI/menu glyph map.
- `story_glyph_map_seed.csv`: partial story-dialogue glyph map, currently covering the confirmed 4F boss / Briareos slice in `DATA001/0012`.

Do not place extracted game files, screenshots, audio, movies, executable modules, or rebuilt images in this directory.
